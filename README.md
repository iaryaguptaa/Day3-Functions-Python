# Day 3: Functions & Code Reusability

This repository contains my Jupyter Notebook submission for the **Day 3** self-learning assignment of the Data Science Internship. The focus of this module is on writing modular, reusable, and maintainable Python code using advanced function concepts.

## Theory & Concepts Covered
* Function definitions, parameters, and return statements
* Default and variable-length arguments (`*args`)
* Variable Scope (Local vs. Global)
* Lambda (Anonymous) Functions
* Recursion
* Functional Programming Operations (`map()`, `filter()`, `reduce()`)

## Practice Programs Included
The enclosed Jupyter Notebook (`Day3_Functions.ipynb`) contains the following implementations:
1. **BMI Calculator**: Calculates Body Mass Index and categorizes health status.
2. **EMI Calculator**: Computes monthly loan EMI using standard financial formulas.
3. **Recursive Factorial**: Calculates the mathematical factorial of a number using recursive function calls.
4. **Fibonacci Series**: Generates the Fibonacci sequence using both iterative and recursive approaches.
5. **Prime Number Checker**: Evaluates whether a given integer is a prime number.
6. **List Operations**: Demonstrates real-world data transformation using `map` (squaring data), `filter` (extracting evens), and `reduce` (accumulating sums).

* **Language:** Python 3
* **Environment:** Jupyter Notebook (VS Code)
